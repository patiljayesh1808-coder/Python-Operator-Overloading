# Python Operator Overloading

## 📌 Project Overview

This project demonstrates **Operator Overloading in Python** using a `book` class and Python's special methods, also known as magic methods.

Operator overloading allows us to define how operators such as `+`, `-`, `*`, `/`, and others behave when they are used with objects of a class.

In this project, two book objects are created, and different operations are performed using their prices and page counts.

## 🎯 Objectives

- Understand operator overloading in Python.
- Learn how to use magic methods.
- Perform arithmetic operations on class objects.
- Implement comparison operators using special methods.
- Practice Python Object-Oriented Programming (OOP).

## 🛠️ Technologies Used

- **Programming Language:** Python
- **Concept:** Object-Oriented Programming (OOP)

## ⚙️ Operations Implemented

| Operator | Magic Method | Operation |
|---|---|---|
| `+` | `__add__()` | Addition |
| `-` | `__sub__()` | Subtraction |
| `*` | `__mul__()` | Multiplication |
| `/` | `__truediv__()` | Division |
| `//` | `__floordiv__()` | Floor division |
| `%` | `__mod__()` | Modulus (remainder) |
| `<` | `__lt__()` | Less than |
| `>` | `__gt__()` | Greater than |
| `==` | `__eq__()` | Equal to |

## 📚 Key Learning

- Operator overloading customizes operators for user-defined objects.
- Magic methods begin and end with double underscores.
- `__add__()` handles `+`, while `__mul__()` handles `*`.
- `__truediv__()` handles `/`, and `__floordiv__()` handles `//`.
- Comparison magic methods allow objects to be compared using operators.
